# Colors

Color setting options. I will gradually transfer all commands where color is set to this system (except for the model and rail color).

All characters are case-insensitive.

## Name

white, black, red, green, blue, yellow, magenta, cyan, white, gray

## One character

0-9 - colors like text

## HEX

12 bit:

RGB
#RGB
xRGB
0xRGB

24 bit:

RRGGBBB
#RRGGBB
xRRGGBB
0xRRGGBB

Non-significant zeros can be discarded. For example, x1122 will be read as x001122

Do not confuse:

- 0xff is 0x0ff and not 0x0000ff
- 5 is 5 and not 0x005
